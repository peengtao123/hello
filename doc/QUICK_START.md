# 快速开始指南

## 📦 安装与运行

### 1. 安装依赖
```bash
npm install
```

### 2. 启动开发服务器
```bash
npm run dev
```

### 3. 访问应用
打开浏览器访问：http://localhost:5173

## 🎯 主要功能页面

### 基础页面
- **首页** (`/`) - 系统仪表盘
- **用户管理** (`/users`) - 用户信息管理
- **商品管理** (`/products`) - 商品信息管理
- **订单管理** (`/orders`) - 订单查看与管理
- **文章管理** (`/articles`) - 第三方API文章展示
- **系统设置** (`/settings`) - 系统参数配置

### 技术演示页面

#### 🧠 深度学习 (TensorFlow.js)
- **路径**: `/tensorflow`
- **功能**: 
  - 神经网络模型训练
  - 实时损失曲线可视化
  - 预测结果对比分析
  - 交互式模型测试

#### 🎨 3D 可视化 (Three.js)
- **路径**: `/three-showcase` → `/three-demo`
- **功能**:
  - 多种几何体展示（立方体、球体、圆环、圆锥）
  - 材质切换（实体/线框）
  - 颜色动态更换
  - 鼠标交互控制（旋转、平移、缩放）
  - 光影效果

#### 🌟 粒子系统
- **路径**: `/particle-demo`
- **功能**:
  - 可配置粒子数量（1000-10000）
  - 动态颜色渐变
  - 实时大小调整
  - 球形分布效果

#### 🏠 全景看房 (VR 360°)
- **路径**: `/panorama`
- **功能**:
  - 360° 全景图浏览
  - 多场景切换（客厅、卧室、厨房）
  - 热点标记导航
  - 自动旋转模式
  - 交互式视角控制
- **操作说明**:
  - 🖱️ 左键拖拽：旋转视角
  - 🖱️ 右键拖拽：平移视角
  - 🖱️ 滚轮：缩放视图
  - 📍 点击红色热点：跳转到其他房间

## 📚 技术栈

- **前端框架**: Vue 3.5+ (Composition API)
- **构建工具**: Vite 8.0+
- **状态管理**: Pinia 3.0+
- **路由管理**: Vue Router 5.0+
- **HTTP 客户端**: Axios 1.15+
- **语言**: TypeScript 6.0+
- **3D 渲染**: Three.js 0.184+
- **深度学习**: TensorFlow.js
- **图表库**: Chart.js
- **测试**: Vitest + Playwright

## 💡 使用提示

1. **首次使用**: 建议先访问"技术学习"菜单下的各个演示页面，了解项目集成的各种技术能力
2. **全景看房**: 需要良好的网络连接以加载高清全景图片
3. **3D 演示**: 建议使用 Chrome、Edge 或 Firefox 等现代浏览器以获得最佳性能
4. **移动端**: 部分 3D 功能在移动设备上可能需要调整视角和交互方式

## 🐛 常见问题

### Q: 全景图加载失败？
A: 检查网络连接，确保可以访问外部图片资源。也可以替换为本地的全景图片。

### Q: 3D 场景显示空白？
A: 检查浏览器控制台是否有错误信息，确保显卡驱动正常，浏览器支持 WebGL。

### Q: 页面卡顿或性能问题？
A: 尝试降低粒子数量、减少几何体复杂度，或关闭阴影效果。
